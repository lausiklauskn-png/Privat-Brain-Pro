# Bestehende Vorschau-Signieridentität

Hier dürfen ausschließlich `import.age` (einmaliger verschlüsselter Transport),
`android-release.enc.json` (dauerhaftes AES-256-GCM-Paket) und
`android-certificate.json` (öffentlicher Pin) eingecheckt werden.

Noch kein Original importiert: Eine Anleitung ist keine Schlüsseldatei und kein
Veröffentlichungsnachweis. Keinen neuen Vorschau-Schlüssel erzeugen.

[Sichere Übernahme und Einzelschritte](../docs/SIGNIERUNG-UND-GITHUB.md).
