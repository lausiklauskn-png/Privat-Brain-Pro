Teil 1

Ursachen deiner Fehler

PunktWas passiert wirklichWie sicher
1 · „Bitte warten“ beim StartZwei Dinge zusammen. Ist das Bedeutungsmodell einmal geladen, startet die App es bei jedem Start von selbst. Und die neue Warte-Zeile aus 1.0.52 sprang bei jeder Arbeit an, die die App im Hintergrund selbst macht. Das Zweite ist schon behoben (Punkt 24), das Erste noch nicht.im Code belegt
3 · „Suchen“ tut nichtsAuf der Startseite gibt es zwei getrennte Suchen mit zwei getrennten Trefferlisten. „Suchen“ im Kasten „Überall suchen“ füllt nur die kleine Liste im Kasten, die große Trefferliste darunter bleibt leer. Die große Liste rechnet nur beim Tippen oder beim Ändern eines Filters. Dazu ist der Knopf „Suchen“ nach dem Tipp weiß auf hellblau und kaum zu lesen.im Prüfbrowser gemessen
4 · Mail öffnen dauert, zweimal „Lesedurchgang“„Lesedurchgang“ ist kein Mail-Abruf, sondern die Texterkennung: beim Öffnen prüft die App jeden Anhang, bei Bildern und Scan-PDFs liest sie den Text in zwei Durchgängen. Davor fragt sie den Anbieter viermal nacheinander (Konten, Ordner, ganze Ordnerliste, dann die Mail).im Code belegt
8 · Bedeutung findet nichtsNicht geklärt. Zwei wahrscheinliche Gründe: die PDFs sind noch nicht „eingeordnet“ (dann sucht die App nur nach Wörtern), oder das Diktat hat das Wort getrennt (Punkt 9). Ich brauche das Suchwort und einen Dateinamen aus deinem Test, dann baue ich genau dafür eine Probe.offen
19 · Klick springt zur falschen MailNach dem Öffnen baut die App die ganze Mail-Liste neu. Dabei springt die Liste an den Anfang, also zur neuesten Mail. Die angeklickte Mail ist geöffnet, aber die Liste zeigt sie nicht mehr.im Code gelesen, nicht gemessen
21 · „Liste / Absender“ bei SucheSo gebaut: sobald ein Suchwort im Feld steht, zeigt „Alle Konten“ immer die flache Liste. Die Knöpfe „Absender“ und „Aufräumen“ werden dann übergangen, ohne es zu sagen.im Code belegt
20 · „Aufräumen“ leerGibt es nichts aufzuräumen, steht nur der Einleitungssatz da und sonst nichts.im Code belegt
