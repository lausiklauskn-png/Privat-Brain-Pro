# Anpassbare Oberfläche .16

Synthetische Chromium-Aufnahmen ohne echte Konten oder private Dateien. Stand
2026-10-20. Kurze Namen stehen rechts neben SVG-Symbolen. Alle acht Ansichten
bleiben erreichbar; schmale Fenster erhalten zusätzliche flache Zeilen.

- Suche: [280](search-280.png), [320](search-320.png), [390](search-390.png), [768](search-768.png), [1280 Pixel](search-1280.png).
- Mail: [320](mail-320.png), [390](mail-390.png), [768](mail-768.png), [1280 Pixel](mail-1280.png).
- Explorer: [320](explorer-320.png), [1280 Pixel](explorer-1280.png).
- Dateiimport: [320](import-320.png), [1280 Pixel](import-1280.png).
- Dashboard: [320](dashboard-320.png), [1280 Pixel](dashboard-1280.png).

Geprüft werden auch 650, 1000 und 1920 Pixel, alle acht Ansichten und vier
Sprachen mit größerer Schrift. Diese Bilder belegen die Browseroberfläche,
keinen Lauf auf einem echten iPhone, Mac, Windows- oder Samsung-Gerät.
Plattformgrenzen: [Bedienung](../../BESCHRIFTUNGEN-UND-ORDNER.md#fensterbreiten-und-betriebssysteme).
